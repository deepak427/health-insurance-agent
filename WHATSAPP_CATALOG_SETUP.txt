📋 Quick Setup (3 Steps):

1️⃣ Get Your Business ID
   → Go to: https://business.facebook.com/settings
   → Click "Business Info" (left sidebar)
   → Copy the "Business ID" (long number like 123456789012345)
   
2️⃣ Add to .env file
   Open hip/.env and add:
   FACEBOOK_BUSINESS_ID=YOUR_BUSINESS_ID_HERE
   
3️⃣ Run Setup Script
   cd hip
   python setup_whatsapp_catalog.py
   
   The script will:
   ✅ Create a WhatsApp Product Catalog via API
   ✅ Add 8 sample insurance policies
   ✅ Give you the Catalog ID to add to .env
   
   Then add the Catalog ID to .env:
   WHATSAPP_CATALOG_ID=YOUR_CATALOG_ID_HERE
   
4️⃣ Restart Server
   Carousel messages now work! 🎉

🔧 Managing Products:

Add New Policy Programmatically:
from whatsapp.catalog_manager import add_product

await add_product(
    catalog_id="YOUR_CATALOG_ID",
    product_id="new_plan_id",
    name="New Travel Plan",
    price="2500",
    description="Comprehensive coverage for Asia"
)

Sync Multiple Policies:
from whatsapp.catalog_manager import sync_policies_to_catalog

policies = [
    {"name": "Plan A", "premium": "2000", "sum_insured": "$50k"},
    {"name": "Plan B", "premium": "3000", "sum_insured": "$100k"}
]
await sync_policies_to_catalog(policies)

🎯 What Happens:

WITH Catalog Setup:
User asks for quotes → Agent sends POLICY_CARDS → 
Backend detects catalog → Sends carousel → 
User swipes beautiful cards → Selects plan → 
Agent continues booking

WITHOUT Catalog Setup:
User asks for quotes → Agent sends POLICY_CARDS → 
Backend checks (no catalog) → Auto-fallback to list → 
User taps list → Selects plan → 
Agent continues booking

Both work! Carousel is just prettier ✨

❓ Troubleshooting:

"Setup script fails with 403 error"
→ Your token needs catalog_management permission
→ Generate new token from Meta App Dashboard

"Can't find Business ID"
→ Go to business.facebook.com/settings
→ Must be Business Admin to see Business Info

"Catalog created but carousel not showing"
→ Make sure WHATSAPP_CATALOG_ID is in .env
→ Restart your server
→ Product IDs must match policy names (auto-generated)

"Want to use existing catalog"
→ Just add WHATSAPP_CATALOG_ID to .env
→ Run sync_policies_to_catalog() to add products
